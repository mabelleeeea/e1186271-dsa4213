# DSA4213 Assignment 1 — Language Models, Embeddings, and Representations

Code for training and comparing next-token language models on WikiText-2 (Part I),
an input-embedding ablation (Part II), and a downstream topic-classification
analysis on AG News (Part III).

## Repository structure

| File | Purpose |
|---|---|
| `config.py` | Shared settings: random seed, generation prompts, decoding settings |
| `data.py` | Downloads WikiText-2, tokenizes, builds the vocabulary, saves token streams to `data/` |
| `ngram.py` | Part I: trigram LM with interpolated Kneser-Ney smoothing (implemented from scratch) |
| `models.py` | Part I–III: RNN, LSTM and causal Transformer LMs |
| `train_lm.py` | Part I–II: one training/evaluation script for every neural LM run |
| `embeddings.py` | Part II: trains skip-gram embeddings and aligns GloVe to the vocabulary |
| `downstream.py` | Part III: frozen-LM features + logistic regression on AG News |
| `plots.py` | Loss-curve figures and summary tables from `results/*.json` |
| `results/` | All metrics, loss histories and generated samples (JSON) + `tables.md` |
| `figures/` | Figures used in the report |
| `logs/` | Console output of every training run |

`data/`, `embeddings/` and `checkpoints/` are generated by the scripts and are not committed.

## Setup

Tested with Python 3.13 and PyTorch 2.14 on macOS (Apple Silicon, MPS backend).

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

The scripts use CUDA if available, otherwise Apple MPS, otherwise CPU.

## Data access

Nothing needs to be downloaded by hand; each script fetches what it needs on first use.

| Data | Source | Used in |
|---|---|---|
| WikiText-2 (raw) | Hugging Face `Salesforce/wikitext`, config `wikitext-2-raw-v1` | Parts I–II (train / validation / test splits as provided) |
| GloVe 6B 100d | `gensim.downloader`, model `glove-wiki-gigaword-100` (~130 MB, cached in `~/gensim-data`) | Part II |
| AG News | Hugging Face `fancyzhx/ag_news` | Part III |

Datasets are downloaded from their public sources at run time and are not redistributed in this repository.

## Reproducing the results

Run from the repository root with the virtual environment active. Times are from an
Apple M-series laptop (MPS).

```bash
# 1. Data and vocabulary (~1 min)
python data.py

# 2. Part I — n-gram baseline (seconds; D tuned on validation)
python ngram.py

# 3. Part I — neural LMs (about 20–25 min each)
python train_lm.py --model rnn         2>&1 | tee logs/rnn.txt
python train_lm.py --model lstm        2>&1 | tee logs/lstm.txt
python train_lm.py --model transformer 2>&1 | tee logs/transformer.txt

# 4. Part II — embeddings (skip-gram ~30 s; GloVe download ~1 min)
PYTHONHASHSEED=42 python embeddings.py --which w2v
python embeddings.py --which glove

# 5. Part II — LSTMs with frozen embeddings (about 21 min each).
#    The random-embedding setting reuses the Part I LSTM (identical configuration).
python train_lm.py --model lstm --emb w2v   2>&1 | tee logs/lstm_w2v.txt
python train_lm.py --model lstm --emb glove 2>&1 | tee logs/lstm_glove.txt

# 6. Part III — downstream classification (~5–10 min, no LM training)
python downstream.py --runs lstm_random transformer_random lstm_w2v lstm_glove \
                     --pooling mean last \
                     --bag_baselines lstm_random lstm_w2v lstm_glove

# 7. Figures and tables
python plots.py
```

Quick smoke test before the full runs: `python train_lm.py --model lstm --epochs 1 --max_batches 30`.

## Seeds and determinism

- `SEED = 42` (in `config.py`) seeds PyTorch, NumPy, data shuffling, generation sampling,
  the AG News subsample and the logistic regression.
- Skip-gram uses one worker thread and must be run with `PYTHONHASHSEED=42` to be reproducible.
- GPU kernels (MPS/CUDA) are not guaranteed bit-for-bit deterministic, so re-running
  neural training may give slightly different numbers (small differences in the last decimals of perplexity).

## Configuration

**Preprocessing (`data.py`)**: lowercased word-level tokens; WikiText `@-@`, `@,@`, `@.@`
markers rejoined; possessives/contractions (`'s`, `'t`, …) kept as single tokens;
headings and blank lines removed; `<eos>` appended to each paragraph; vocabulary = 20,000
most frequent training-split types including `<pad>`, `<unk>`, `<eos>`; all other words → `<unk>`.

**Evaluation protocol (all LMs)**: every token of the test stream except the first is
predicted exactly once from preceding tokens only. Neural models see non-overlapping
64-token windows; padded positions are excluded from the loss. Reported metric:
average cross-entropy (nats/token) and perplexity = exp(cross-entropy).

**n-gram (`ngram.py`)**: trigram, interpolated Kneser-Ney, single discount D tuned on
validation over {0.5, …, 0.95} (selected D = 0.9).

**Neural LMs (`train_lm.py` defaults)**:

| Setting | Value |
|---|---|
| Input embedding dim | 100 (all models; matches GloVe-100d) |
| Hidden size / d_model | 256 |
| Layers | 2 |
| Transformer heads / FFN size | 4 / 1024, pre-LayerNorm, learned positions, causal mask |
| Dropout | 0.3 |
| Context length | 64 tokens |
| Batch size | 64 windows |
| Optimiser | AdamW, lr 1e-3, gradient clipping 1.0 |
| Training budget | 10 epochs, no early stopping, same for every run |
| Model selection | checkpoint with lowest validation loss |
| Decoding | top-k = 40, temperature 0.8, 30 new tokens, `<pad>`/`<unk>` never sampled |

**Part II (`embeddings.py`)**: skip-gram (gensim Word2Vec), dim 100, window 5,
5 negative samples, 5 epochs, training split only. Rows without a pretrained vector
(`<eos>`, and words missing from GloVe) are initialised from N(0, σ²) with σ = std of the
table's real vectors; `<pad>` is zero. The whole embedding table is frozen.

**Part III (`downstream.py`)**: AG News, 8,000 train / 2,000 validation (seeded sample of
the official train split) / 7,600 test (official test split). Inputs use the same
tokenizer and vocabulary, truncated to 64 tokens. Features: mean of hidden states over
non-padding tokens, or the hidden state at the last real token; baseline = mean of raw
input embeddings with no LM. Classifier: standardised features + logistic regression,
C ∈ {0.01, 0.1, 1, 10} chosen by validation macro-F1.

## Outputs

- `results/ngram.json`, `results/<model>_<emb>.json`: test perplexity, loss history,
  parameter counts, training time, inference throughput, generated samples.
- `results/emb_w2v.json`, `results/emb_glove.json`: vocabulary coverage, missing words,
  training/load time, nearest neighbours.
- `results/downstream.json`, `results/downstream_errors.json`: accuracy, macro-F1,
  confusion matrices, misclassified examples.
- `results/tables.md`, `figures/*.png`: generated by `plots.py`.
